CORE PRODUCT DECISION FOR THIS STEP

After a user:
- registers / logs in
- completes onboarding

they should NOT be sent directly into the 40-day process.

Instead, they must land on a pre-process main screen (dashboard-like home).

On that screen:
- the top primary state must say:
  "Empezar mi proceso"
  instead of "Día 1"
- the rest of the screen can keep the existing dashboard structure as much as possible
- there must be a persistent Ego guide button near the bottom center

The real process begins only when the user explicitly starts it.

Then the sequence should be:
1. pre-process home
2. Ego Guide introduction
3. Portal / Umbral
4. real process start
5. dashboard showing Día 1
