Build a Spanish-language web app called “Ego Consciente”.

Goal:
Create the first MVP shell of a reflective self-observation app where “the Ego” speaks as a narrator and helps the user observe internal patterns without diagnosing or labeling them.

Core product principles:
- This is not therapy.
- The app must not diagnose the user.
- The app must never label the user.
- Avoid phrases like “you are X”.
- Prefer language like “tu sistema tiende a…”.
- The core framework is PEA:
  - Pensamiento
  - Emoción
  - Acción
- The user progresses through a 40-day journey.
- The experience should feel calm, introspective, minimal, elegant, and emotionally safe.

Important scope rule:
For this first version, build the interface, navigation, structure, and mock functionality first.
Use mock data and mock chat responses if needed.
Do not require external APIs yet.
Keep the project easy to run.

Tech requirements:
- Use Next.js + TypeScript + Tailwind CSS
- Mobile-first responsive design
- Clean folder structure
- Reusable components
- Keep the code simple and maintainable
- Avoid overengineering

Pages to build:
1. Landing / welcome page
2. Login page
3. Register page
4. Main dashboard
5. Chat page with the Ego
6. Daily PEA reflection page
7. Progress page showing current day out of 40

Design direction:
- Premium introspective wellness style
- Warm neutral colors
- Soft spacing
- Elegant typography
- Minimal UI
- Clear CTA buttons
- Calm visual hierarchy

All visible UI copy must be in Spanish.
