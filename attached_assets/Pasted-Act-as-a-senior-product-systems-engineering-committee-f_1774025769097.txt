Current issue:
The user can be on stage 1 but the system does not have a clear human-centered completion flow.
We do NOT want completion to be a blind click.
We want:
- there is still a "Completar etapa" button
- BUT clicking it must validate whether the stage has enough minimum information
- if information is missing, the Ego must step in and ask for what is missing
- only after enough information exists should the stage complete and the next one unlock

CORE PRODUCT RULE

A stage is NOT completed just because the user clicked a button.
A stage is completed when the system has enough minimum information for that stage.

For this implementation version, we will use a universal minimum structure for all stages:
- pensamiento
- emoción
- acción (or avoidance / what the user did or did not do)

We are NOT implementing full AOE scoring yet.
We are implementing the minimum data capture + completion validation system.

4. COMPLETION VALIDATION
When the user clicks "Completar etapa", run validation.

Minimum valid condition for now:
- thought exists and is not empty
- emotion exists and is not empty
- action exists and is not empty

Also reject obviously too-thin placeholders such as:

- empty spaces
- repeated punctuation only

You do NOT need AI for this.
Use deterministic validation for now.

5. IF VALIDATION PASSES
If enough information exists:
- set completion_ready = true
- set completion_missing = []
- mark current stage as completed
- set completed_at
- unlock next stage
- move next stage to active / in_progress
- navigate or offer CTA to next stage

6. IF VALIDATION FAILS
If information is insufficient:
- do NOT complete the stage
- do NOT unlock the next one
- the Ego must step in

7. EGO INTERVENTION MODE
Implement a lightweight “Ego intervention” block when validation fails.

This can be:
- inline panel on the stage page
OR
- reuse the existing EGO guide overlay in a special completion-assist mode

The Ego should say something like:
"Antes de avanzar, hay algo que tu sistema aún no ha terminado de mostrar."

Then generate deterministic follow-up prompts based on what is missing:

If thought missing:
- "Antes de avanzar, necesito una frase clara de lo que estabas pensando en esa situación."

If emotion missing:
- "¿Qué sentiste exactamente? Evita algo muy general si puedes. Nombra la emoción más real."

If action missing:
- "¿Qué hiciste o qué evitaste hacer en ese momento?"

If multiple missing:
- ask them one by one in a clean order

8. SAVE EGO FOLLOW-UP RESULTS
When the user answers the follow-up, save the answer into the missing field in stage_progress.
Increase ego_followup_count by 1 each time the Ego had to intervene.

9. RE-RUN VALIDATION
After the user answers the missing info:
- validate again
- if complete, unlock next stage
- if still incomplete, continue gently with one more follow-up
- do not create an infinite loop
